# Práctica 01 - Crear directorios y subir un documento PDF

## Objetivo

Crear una estructura organizada dentro del repositorio Developers_Lab para almacenar documentación relacionada con Git y subir un documento PDF como material de referencia.

---

## Estructura inicial

```text
Developers_Lab
│
└── README.md
```

---

## Actividades realizadas

### 1. Creación del repositorio

Se creó el repositorio:

```text
Developers_Lab
```

configurado con:

- Rama principal: main
- Visibilidad: Public
- Archivo README.md inicial

---

### 2. Creación del directorio Herramientas

Se creó:

```text
Herramientas/
```

con su correspondiente archivo:

```text
README.md
```

---

### 3. Creación del directorio Git

Dentro de Herramientas se creó:

```text
Herramientas/Git/
```

junto con su archivo:

```text
README.md
```

---

### 4. Subida del documento PDF

Se añadió el archivo:

```text
Guía_Git.pdf
```

utilizando:

```text
Add file
→ Upload files
```

---

### 5. Creación del directorio Practicas

Se creó:

```text
Herramientas/Git/Practicas/
```

para almacenar ejercicios y procedimientos documentados.

---

## Resultado final

```text
Developers_Lab
│
├── README.md
│
└── Herramientas
    │
    ├── README.md
    │
    └── Git
        │
        ├── README.md
        ├── Guía_Git.pdf
        │
        └── Practicas
            │
            ├── README.md
            └── P01_Crear_Directorio_y_Subir_PDF.md
```

---

## Conceptos aprendidos

- Repositorio
- Rama principal (main)
- Commit
- README.md
- Organización jerárquica
- Subida de archivos
- Historial de cambios

---

## Conclusión

Se ha creado una estructura organizada para almacenar documentación relacionada con Git y se ha subido correctamente un documento PDF al repositorio.
